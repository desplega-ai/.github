## What we build

Two products, one philosophy: agents should do the repetitive work so people can do the interesting work.

### 🐝 agent-swarm

A framework for running fleets of AI coding agents — a lead agent that plans and delegates, worker agents that execute, all coordinating through a shared task pool, memory, and messaging layer. Open source core, with a hosted cloud offering for teams that don't want to run their own infra.

[![agent-swarm.dev](https://img.shields.io/badge/agent--swarm.dev-F59E0B?style=flat-square)](https://agent-swarm.dev)
[![GitHub](https://img.shields.io/badge/desplega--ai%2Fagent--swarm-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/desplega-ai/agent-swarm)

### ✅ desplega.ai

QA with AI. Record how a user interacts with your web app, and desplega.ai turns that recording into a durable, automated end-to-end test — no brittle selectors, no manual script maintenance. Ships with a CLI (`qa-use`) and a CI Action so tests run wherever your pipeline does.

[![desplega.ai](https://img.shields.io/badge/desplega.ai-2563EB?style=flat-square)](https://desplega.ai)
[![GitHub](https://img.shields.io/badge/desplega--ai%2Fqa--use-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/desplega-ai/qa-use)

> agent-swarm and desplega.ai are separate, parallel products — both built by Desplega Labs, neither a feature of the other.
